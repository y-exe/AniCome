# コメント取得・保存

## 再生時

1. PlaybackMetadataが動画アプリの作品名・話数・再生位置を解析します。
2. AppCoordinatorとRepositoryが作品・話数を照合し、選択された取得元を検索します。
3. 保存済みコメントや自動キャッシュがあれば再利用し、不足する取得元を取得します。
4. CommentTimelineが動画の尺や同期マーカーを使って取得元ごとの時刻を調整します。
5. 描画側へ反映します。追加取得で既存コメントを消さず、固定コメント・AAのコマンドや空白・改行を保持します。

取得対象は公式、dアニメ、分割・コメント専用動画、実況過去ログ、ニコ生アーカイブです。再生情報や取得元の公開状態によっては検索・同期できない場合があります。手動取得や時刻補正で調整できます。

## 事前ダウンロード

作品候補から作品を確定し、APIの各話タイトル・話数とニコニコ動画の情報を照合します。期・クールや通算話数を区別し、指定した取得元を作品・話数ごとに保存します。チャンネルはURL・数値ID・スラッグでも指定できます。

保存予約はDownloadRepository・ReservationScheduler・WorkManagerが管理します。コメント本体はファイル、一覧と予約などのメタデータはRoomへ保存します。自動取得のキャッシュは手動保存と分け、期限を設定します。

保存済みファイルの読み込み・取得元の合成・別動画への差し替えを変更するときは、コメントの欠落、重複、保存データの上書き、途中での表示停止を回帰テストしてください。

## 描画と試し表示

app/src/main/assets/overlay.jsがAndroidと同梱のniconicommentsを橋渡しします。ライブラリ本体はvendor/、試し表示のコメントはニコニコ連携後に取得し、端末のfiles/preview/へ保存します。試し表示の動画本体は同梱しません。

描画テストはtests/rendering/、作品・各話の固定データはapp/src/test/resources/にあります。認証済み動画情報・個人の書き出しコメント・過去の取得作業用ファイルはGitへ追加しません。
