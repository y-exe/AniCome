## 更新内容

- 事前ダウンロードの作品検索にbangumi-dataを導入。ニコニコ公式チャンネルと各話の動画を直接照合するよう改善。
- 保存した作品・チャンネルの対応と、手動で差し替えた動画を再生中の自動取得でも再利用するよう改善。
- 作品画像と各話のサムネイルの取得・補完を改善。新しい動画情報APIの画像項目にも対応。
- コメントを取得できない場合に、通信・アクセス制限・同期不足などの原因を区別するよう改善。
- 横画面のコメント表示範囲を動画の位置に合わせて調整。U-NEXTはユーザー補助なしでもカメラ穴の余白を考慮。
- 視聴アプリ別設定の適用範囲を表示位置だけに変更。文字サイズ・不透明度・速度は全アプリ共通に統一。
- コメント表示の初期値を文字サイズ15・不透明度75%・速度65%・合計最大7,000件に変更。
- 試し表示のコメント数を、画面を閉じても保持するよう改善。

※どれをダウンロードすればいいか迷ったら `AniCome-vX.X.X-universal-release.apk`
